## 二、用户角色与旅程分析

### 角色目录（Persona Catalog）

```
P1: 首次设置用户 (First-Time User)
   └─ 从未使用过 Authenticator，需要引导完成首次设置

P2: 日常 TOTP 用户 (Daily TOTP User)
   └─ 已有账户，每天查看 TOTP 码进行登录

P3: Push MFA 用户 (Push MFA User)
   └─ 启用 Push，需要在其他设备登录时审批

P4: 多设备用户 (Multi-Device User)
   └─ 在手机、平板、电脑间同步/管理账户

P5: 安全敏感用户 (Security-Conscious User)
   └─ 关注账户安全、查看活动日志、管理设备

P6: 离线场景用户 (Offline User)
   └─ 经常在无网络环境下使用 TOTP

P7: 恢复场景用户 (Recovery User)
   └─ 手机丢失/更换，需要恢复账户
```

## 三、缺失功能详细分析

### 🔴 P0 — 核心缺失（严重影响用户体验）

#### 1. 账户搜索与过滤
- **现状**: 账户以简单列表展示，无搜索功能
- **影响**: 当账户 >10 个时，用户需要滚动大量内容寻找目标账户
- **参考**: Google Authenticator 支持搜索；Microsoft Authenticator 有最近使用排序
- **建议**: 在首页 Header 添加搜索栏；支持按名称/用户名过滤

#### 2. 账户分类/分组
- **现状**: 所有账户平铺，无分组
- **影响**: 工作账户和个人账户混杂，难以管理
- **参考**: Authy 支持分组；1Password 有标签系统
- **建议**: 添加 `group` 字段（工作/个人/金融/社交）；支持按组折叠

#### 3. 账户详情与编辑
- **现状**: TotpCard 只有复制和删除，无法编辑
- **影响**: 账户名称拼写错误无法修改，只能删除重建
- **建议**: 点击卡片进入详情页，支持编辑名称、用户名、图标、分组

#### 4. 账户图标/Logo 自动识别
- **现状**: 所有账户使用统一的 Shield 图标
- **影响**: 视觉上难以快速区分不同服务
- **参考**: Google/Microsoft Authenticator 自动显示服务 logo
- **建议**: 
  - 内置常见服务图标映射（GitHub, Google, AWS, 微信, 支付宝等）
  - 支持用户上传自定义图标
  - 根据 issuer/name 自动匹配图标

#### 5. TOTP 一键同步后端（账户绑定）
- **现状**: `add` 页面只能手动输入 secret，没有从后端获取 TOTP 的功能
- **影响**: 用户必须手动从服务端复制 secret，容易出错
- **后端能力**: `POST /mfa/totp/enable` 可生成 secret + QR 码
- **建议**: 新增「从 Autional 绑定」Tab，调用后端 API 获取 secret 并自动添加

#### 6. 深色/浅色主题切换（实际功能缺失）
- **现状**: settings 页面显示「深色模式 · 默认」，但点击无反应
- **影响**: UI 提示有功能但实际不可用，造成困惑
- **建议**: 实现主题切换逻辑（Tailwind dark mode）；持久化用户偏好

#### 7. 网络状态指示
- **现状**: 无任何网络连接状态显示
- **影响**: Push 订阅失败、API 调用失败时用户不知道为什么
- **建议**: 顶部状态栏显示在线/离线指示器；API 失败时显示重试按钮

### 🟡 P1 — 重要缺失（影响产品完整性）

#### 8. 活动/安全日志页面
- **现状**: 无历史活动查看功能
- **用户故事** (P5): "我想查看最近有哪些登录请求和审批记录"
- **后端能力**: `GET /mfa/push/history` 已有
- **建议**: 新增 `/activity` 页面，展示 Push 审批历史 + 设备登录记录

#### 9. 设备管理页面
- **现状**: settings 中 Push 开关只能全局启用/禁用
- **用户故事** (P4): "我想查看在哪些设备上注册了 Push，并可以撤销某台设备"
- **后端能力**: `GET /push/subscriptions` 可列出设备
- **建议**: 新增「已注册设备」列表，显示设备名称 + 平台 + 注册时间 + 撤销按钮

#### 10. 备份码查看与生成
- **现状**: settings 只有本地 JSON 导出导入，没有云备份码
- **用户故事** (P5): "我想查看我的 MFA 备份码"
- **后端能力**: `POST /mfa/backup-codes/generate` + `GET /mfa/backup-codes`
- **建议**: settings 新增「备份码」区块：生成按钮 + 10个码展示 + 剩余数量

#### 11. 生物识别解锁（WebAuthn/指纹）
- **现状**: 只有 PIN 解锁
- **用户故事** (P5): "我希望用指纹快速解锁"
- **建议**: 检测平台能力，支持 WebAuthn / Touch ID / Face ID 作为解锁方式

#### 12. 账户排序与置顶
- **现状**: 按添加时间排序，无法调整
- **用户故事** (P2): "我最常用的账户应该在最上面"
- **建议**: 支持拖拽排序；支持「置顶」功能；支持按最近使用自动排序

#### 13. 导入其他 Authenticator 格式
- **现状**: 仅支持自定义 JSON 格式
- **用户故事** (P7): "我从 Google Authenticator 迁移过来"
- **参考**: Google Authenticator 支持导出二维码；Authy 支持迁移工具
- **建议**: 支持 Google Authenticator 迁移二维码（otpauth-migration）解析

#### 14. TOTP 码批量复制
- **现状**: 只能逐个复制
- **用户故事**: "我需要同时复制多个验证码"
- **建议**: 长按进入多选模式，批量复制

### 🟢 P2 — 增强体验（锦上添花）

#### 15. 首页 Dashboard / 概览
- **现状**: 首页只有账户列表，无汇总信息
- **建议**: 
  - 顶部统计卡片：账户总数、Push 启用状态、最近活动
  - 安全评分（基于 MFA 启用率、备份码是否生成等）
  - 最近审批快捷入口

#### 16. 安全评分系统
- **用户故事** (P5): "我的账户安全状况如何？"
- **评分维度**:
  - TOTP 账户数量 (+10/个，上限50)
  - Push MFA 是否启用 (+20)
  - 备份码是否生成 (+15)
  - PIN/生物识别是否设置 (+10)
  - 云备份是否启用 (+5)
- **建议**: 在首页或 settings 顶部显示环形进度条

#### 17. 震动/声音反馈
- **现状**: 复制 TOTP 码时无触觉反馈
- **建议**: 复制成功时触发短震动（navigator.vibrate）；Push 通知到达时播放提示音

#### 18. 快捷操作（Widget/Long Press）
- **现状**: 长按卡片无快捷菜单
- **建议**: 长按显示快捷操作菜单：复制、编辑、置顶、删除

#### 19. 国际化 (i18n)
- **现状**: 全中文界面
- **建议**: 支持中英文切换（利用后端 locales）

#### 20. 账户过期提醒
- **用户故事**: "某个服务的 TOTP 密钥可能被轮换"
- **建议**: 检测长期未使用的账户，提示用户检查是否仍然有效
